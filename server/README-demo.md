# 🎬 现场演示怎么起(照着抄就行)

这一页写给**完全不懂代码的人**。你只需要会一件事:打开"终端"这个 App,把下面的命令复制进去,按回车。

需要开 **两个终端窗口**。一个跑后端,一个跑公网地址。两个都要一直开着,别关。

---

## 🟢 第一步:起后端

打开终端,粘贴这一行,回车:

```
cd ~/code/spatial-memory && bash server/run.sh
```

**你会看到**:刷一堆字,大概等 10 到 15 秒,最后停在一行 `Uvicorn running on http://0.0.0.0:8777`。

**停在那儿就是对的**,不要按任何键,不要关这个窗口。它看起来"卡住了"就是正常状态。

想确认真的活了:浏览器打开 `http://localhost:8777/server/upload.html`,能看到页面就行。

---

## 🟡 第二步:起公网地址

**再开一个新的终端窗口**(在终端里按 `Command + N`),粘贴这一行,回车:

```
cd ~/code/spatial-memory && bash server/tunnel.sh
```

**你会看到**:等几秒,然后跳出一个框:

```
════════════════════════════════════════
  ✅ 公网地址已就绪

  新人(你自己)开这个:
      https://某几个英文单词.trycloudflare.com/server/host.html

  宾客扫的码指向这个:
      https://某几个英文单词.trycloudflare.com/join
════════════════════════════════════════
```

那串 `https://某几个英文单词.trycloudflare.com` 就是现场要用的地址。

**这个窗口也别关。**

### ⚠️ 这一步要知道的事

- 这个地址**全世界都能打开**,没有密码。地址是随机的,不会被搜到,短时间演示没问题。
- 演示一结束,**回到这个窗口按 `Control + C`**,地址立刻作废。
- 电脑别睡着。合上盖子地址就断了。建议插电源,并且把"睡眠"关掉。

---

## 🔵 第三步:手机扫码

1. 你自己的电脑浏览器打开上面那个 **`/server/host.html`**,这是新人后台。
2. 页面上会显示一个**大二维码**。
3. 让宾客用手机相机对着扫,直接跳进 H5,不用装 App、不用注册。
4. 宾客填个昵称,就能看到任务、传照片。

**投屏建议**:把 host 页面投到大屏,二维码就一直挂在那儿,谁都能扫。

---

## 🔴 演示完了怎么关

按顺序来:

1. 到**第二个窗口**(跑 tunnel 的),按 `Control + C`。
   看到"公网地址已关闭"就对了。这时外面的人已经打不开了。
2. 到**第一个窗口**(跑后端的),按 `Control + C`。
3. 两个窗口都可以关了。

照片和空间数据都存在你自己电脑上的 `server/spaces/` 里,关掉服务不会丢。

---

## 🆘 出岔子了怎么办

**问题:第二步报"本机 :8777 好像没在跑"**
→ 第一步的窗口没起来,或者被你不小心关了。回去重跑第一步。

**问题:第二步等了很久,报"没拿到公网地址"**
→ 网络问题。换个网络(比如开手机热点给电脑用)再试一次。

**问题:手机扫码打开是空白/转圈**
→ 先在你自己手机上试那个地址。如果电脑上能开、手机开不了,大概率是第一步的窗口挂了,回去看看那个窗口有没有报红字。

**问题:现场网巨烂**
→ 别硬撑。让宾客连**你电脑的同一个 Wi-Fi**,然后用局域网地址(host 页面上会一起显示,长得像 `http://192.168.x.x:8777`)。局域网不走公网,快得多。

**问题:二维码扫不出来**
→ 把屏幕亮度调到最高,让手机离屏幕 20 到 30 厘米。投影仪画面糊的话,改成让宾客扫你手机屏幕上的同一个码。

---

## 📋 演示前 5 分钟自检清单

- [ ] 电脑插了电源
- [ ] 系统睡眠已关掉(系统设置 → 锁定屏幕 → 全部设成"永不")
- [ ] 第一步窗口开着,停在 `Uvicorn running`
- [ ] 第二步窗口开着,拿到了公网地址
- [ ] 自己的手机先扫一次,确认真的能进
- [ ] host 页面已投屏,二维码肉眼看得清

## 🔧 附:二维码是自己实现的

`server/qr.js` 是从零手写的二维码生成器,没有引用任何外部库,断网也能画。
改动它之后一定要跑一遍自检:

```
cd ~/code/spatial-memory && node server/qr_selftest.mjs
```

最后一行必须是 `0 失败`。这个自检会拿 macOS 系统自带的扫码器真的扫一遍生成的码,
所以它绿了基本就等于手机能扫出来。
